# Integração KSI para BI

> **Repositório vitrine.** Apenas apresentação do projeto. O código-fonte é privado. Autor: Caio Alba de Camargo.

Central de integração de dados que leva informações do sistema KSI para uma base MySQL e para dashboards em Power BI, de forma automatizada e independente do sistema de origem.

## O que faz
- Extrai dados do KSI de forma programada.
- Carrega e organiza em MySQL para consulta.
- Alimenta relatórios e dashboards no Power BI.
- Inclui um agente que apoia consultas sobre os dados.

## Tecnologias
Python, MySQL, Power BI.
